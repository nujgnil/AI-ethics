# EDA Analysis and Visualization Guide

This README documents how the EDA summaries and visualizations are produced in this project, and how to reproduce the figures for paper writing.

## Purpose

The EDA workflow has two stages:
1. **Summary generation**: scan raw and processed datasets to produce CSV/JSON summaries.
2. **Visualization**: plot dataset composition, data quality, text statistics, themes, and semantic structure.

The main notebook for figures is `notebooks/eda_visualization.ipynb`.

---

## Data Locations

**Raw datasets** are expected under:
- `Data\raw\hendryicks-ethics\`
- `Data\raw\normbank\`
- `Data\raw\mfd2\`
- `Data\raw\mfrc\`
- `Data\raw\moralbench\`

**Processed datasets** are expected under:
- `Data\processed\<dataset_name>\*.csv`

---

## EDA Summary Outputs

Generated by:
- `src\eda_raw.py`
- `src\eda_processed.py`

Outputs:
- Raw EDA: `Data\eda\raw\`
  - `raw_dataset_summary.csv`
  - `raw_dataset_summary.json`
  - `raw_file_summary.csv`
  - `raw_file_summary.json`
- Processed EDA: `Data\eda\processed\`
  - `processed_file_summary.csv`
  - `processed_file_summary.json`

These are the inputs used by the visualization notebook.

## How To Generate EDA Summaries

From the project root:

```powershell
# Raw summaries
python src/eda_raw.py

# Processed summaries
python src/eda_processed.py
```

Alternatively, if you already run the full preprocessing pipeline:

```powershell
python src/run_preprocess_all.py
```

## Visualization Notebook

Primary notebook:
- `notebooks/eda_visualization.ipynb`

Other reference notebooks:
- `notebooks/eda_raw.ipynb` (raw summary generation)
- `notebooks/eda_processed.ipynb` (processed summary generation)

### Key parameters

In `notebooks/eda_visualization.ipynb`, set:
- `DATASET_NAME`: which processed dataset to load
- `FILE_NAME`: optional CSV name inside the dataset folder
- `MAX_ROWS`: sampling cap for heavy plots

## Figures Produced

### Dataset Composition and Quality
- Total rows by dataset (raw + processed)
- File size distribution
- Empty text/label counts and rates
- Text length distribution (median, p95)
- Label distribution (if available)

### Content and Theme
- Top tokens (unigrams)
- Top n-grams (bigrams/trigrams with fallback)
- Word cloud (optional, requires `wordcloud`)
- Topic modeling (NMF + TF-IDF)

### Semantic Structure
- 2D embedding (UMAP if available, else SVD)
- KMeans clustering + silhouette score
- Cross-dataset similarity (TF-IDF centroid cosine heatmap)

### Optional Model Behavior (if predictions exist)
- Confusion matrix
- Error vs text length

## Troubleshooting

### "empty vocabulary" in n-gram plots
This happens when the dataset is very short or stopwords remove everything. The notebook cell already falls back by:
1. Removing stopwords and lowering `min_df`
2. Falling back to unigrams

### Missing UMAP
If UMAP isn’t installed, the notebook uses SVD instead.

### Missing WordCloud
If `wordcloud` isn’t installed, the cell prints a message and skips.

### Missing raw/processed summaries
Run:
```powershell
python src/eda_raw.py
python src/eda_processed.py
```

## Suggested Narrative for Paper

1. **Dataset coverage**: total rows by dataset, file counts.
2. **Data quality**: empty text/label rates, length statistics.
3. **Class balance**: label distributions.
4. **Content themes**: top n-grams and topics.
5. **Semantic structure**: embeddings and clustering.
6. **Cross-dataset similarity**: centroid similarity heatmap.
7. **Limitations**: sampling caps, stopword filtering, and unsupervised topic interpretation.
