# Logbook Template

Date: YYYY-MM-DD
Author: <name>
Project: <project name>
Status: Draft / Final

Purpose
One paragraph describing the intent of the entry and how it will be used in the report.

Scope
- Data sources or scripts used
- Files or folders touched
- Time window or experiment window

Background and rationale
- Why this work is needed
- Links to prior logbook entries or decisions

Methods
- Step-by-step overview of what was done
- Parameters, thresholds, or configuration choices
- Any deviations from standard procedure

Inputs and outputs
- Inputs: list of datasets, files, or versions
- Outputs: generated files and their locations

Results (quantitative)
- Tables, counts, or summary statistics
- Any notable distributions or anomalies

Results (qualitative)
- Short narrative of patterns or observations
- 3-5 example cases (optional)

Quality checks
- Missingness checks
- Duplicate checks
- Split leakage checks
- Sanity checks and outcomes

Decisions and justifications
- Key decisions made and why
- Alternatives considered and why rejected

Limitations and risks
- Known constraints or sources of bias
- What is not covered or missing

Implications for the report
- How this will be described in the dissertation
- Which sections it supports (methods, results, discussion)

Next steps
- Short, ordered list of follow-up tasks

Reproducibility
- Commands run
- Scripts used
- Random seeds (if applicable)
