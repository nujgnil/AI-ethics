# Preprocessing Summary

This document records what has been implemented and produced for preprocessing in this project, so it can be referenced in reports/papers.

---

## Purpose

The preprocessing pipeline standardizes multiple ethics datasets into a consistent, analysis-ready format under `Data\processed\`. This enables:

- Comparable model training across datasets.
- Consistent EDA and visualization.
- Reproducible downstream evaluation.

---

## Pipeline Scripts

All preprocessing scripts are in `scripts\preprocessing\`:

- `preprocess_ethics.py`
- `preprocess_normbank.py`
- `preprocess_mfrc.py`
- `preprocess_mfd2.py`
- `preprocess_moralbench.py`
- `preprocess_utils.py`
- `run_preprocess_all.py` (driver to run all + processed EDA)

### Entry points

Run a single dataset:

```powershell
python scripts/preprocessing/preprocess_ethics.py
```

Run everything:

```powershell
python scripts/preprocessing/run_preprocess_all.py
```

---

## Inputs (Raw Data)

Raw datasets are expected under:

- `Data\raw\hendryicks-ethics\`
- `Data\raw\normbank\`
- `Data\raw\mfd2\`
- `Data\raw\mfrc\`
- `Data\raw\moralbench\`

---

## Outputs (Processed Data)

Processed datasets are written to:

```
Data\processed\
  ethics\
  normbank\
  mfd2\
  mfrc\
  moralbench\
```

Each dataset folder contains:

- A primary CSV (e.g., `ethics.csv`).
- A JSONL version (if generated by the script).
- Summary and label summary artifacts (e.g., `summary.csv`, `label_summary.csv`).
- Duplicate reports (when applicable) to track overlaps.

---

## EDA Hook (Processed)

The driver script `run_preprocess_all.py` also triggers:

```powershell
python scripts/EDA/eda_processed.py
```

which updates:

- `Data\eda\processed\processed_file_summary.csv`
- `Data\eda\processed\processed_file_summary.json`

## Notes / Caveats

- `moralbench` is prompt-only in the current processed form (no labels).
- `mfrc` is currently handled as multi-label, which is not yet supported in `model_train.py` without additional label mapping.
- The preprocessing pipeline assumes datasets are already in the raw folders listed above.
